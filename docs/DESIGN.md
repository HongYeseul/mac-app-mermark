# 디자인 노트

Mermark의 색과 아이콘을 어떻게 정했는지, 어디를 고쳐야 하는지 적어둡니다.

---

## 색상

![Mermark 색상 팔레트](palette.png)

메인 색상은 **민트**입니다.

### 왜 민트인가

처음에는 시스템 기본 파랑에 보라(태그)를 얹은 상태였습니다. 보라는 노트·협업 도구가
많이 쓰는 색이라 앱 이미지가 겹쳤고, 겹치지 않는 색을 새로 골랐습니다.

후보를 추릴 때 쓴 기준은 세 가지였습니다.

1. **다른 서비스와 겹치지 않을 것** — 보라·형광 초록·빨강-주황은 이미 쓰는 곳이 많아 제외
2. **로고와 UI를 같은 색조로 묶을 수 있을 것** — 앱 아이콘에도 쓸 색이므로
3. **라이트·다크 양쪽에서 읽힐 것**

민트·세이지·제이드 세 가지를 실제로 렌더해 비교한 뒤 민트로 정했습니다.
청록이 가장 선명해 로고로 놓았을 때 존재감이 좋고, 앱 이름(Mermaid = 바다)과도 연결됩니다.

### 한 값이 아니라 단계로 쓴다

이 결정의 핵심입니다. **파스텔 톤 하나만 쓰면 안 됩니다.** 로고처럼 넓은 면적에서는
부드럽고 좋지만, 흰 배경 위 글자로 쓰면 대비가 모자라 흐려집니다.
그래서 같은 색조를 밝기 단계로 나눠 역할별로 씁니다.

| 용도 | 라이트 | 다크 |
|---|---|---|
| 로고 · 큰 면적 | `#45C7B6` | `#45C7B6` |
| 글자 · 아이콘 (태그, 선택 강조) | `#17786B` | `#7EDCCC` |
| 태그 배경 | `#45C7B6` 16% | `#7EDCCC` 22% |
| 코드 | `#6B7A8F` | `#9BB0C7` |

`#17786B`는 흰 배경 대비 5.3:1로 WCAG AA를 넘습니다.

### 다른 색은 왜 그대로 두었나

- **코드** — 원래 청록이었는데 메인 색과 같은 계열이라 헷갈렸습니다. 차분한 슬레이트로 옮겨
  "브랜드 색"과 "코드"의 역할이 구분되게 했습니다.
- **목록 표시(주황)** — 민트의 보색 쪽이라 오히려 구분이 쉬워 유지했습니다.
- **링크(파랑)** — 링크가 파랑인 것은 오래된 관습이라 바꾸지 않았습니다.

### 테마

설정(`⌘,`)에서 다섯 가지 중 고를 수 있습니다 — 민트·세이지·제이드·코퍼·플럼.
고른 색은 에디터 강조, 프리뷰 태그·툴바, 사이드바 선택, 그리고 **Dock 아이콘**에 함께 적용됩니다.

Finder에 보이는 아이콘은 앱 번들 안의 `.icns`라 실행 중에는 바뀌지 않습니다.
바꾸려면 번들을 고쳐야 하는데 코드 서명이 깨지므로 하지 않습니다.
Dock 아이콘은 `NSApplication.applicationIconImage`로 실행 중에 다시 그립니다.

### 고칠 때 주의할 점

색 값은 [`Mermark/Theme.swift`](../Mermark/Theme.swift) 한 곳에만 있습니다.
프리뷰(웹뷰)는 Swift 상수를 쓸 수 없지만, `Brand.previewCSS()`가 CSS 변수를 만들어
주입하므로 값이 두 벌로 갈라지지 않습니다. `preview.html`은 `var(--brand-*)`만 참조합니다.

## 앱 아이콘

<img src="app-icon.png" width="128" alt="Mermark 앱 아이콘">

노드 하나에서 둘로 갈라지는 **흐름도**입니다. 이 앱이 다루는 것이 다이어그램이라는 표시이고,
Mermaid 흐름도의 생김새를 그대로 줄인 모양입니다.

- 바탕: `#5AD5C2` → `#2FA593` 세로 그러데이션 (위가 밝은 쪽, macOS 관례)
- 마크: 흰색
- 여백과 모서리: macOS 아이콘 규격에 맞춰 캔버스의 9.77% 여백, 모서리 반경 22.37%

### 작은 크기에서는 마크를 바꾼다

16·32px에서는 갈래가 뭉개져 한 덩어리로 보였습니다. 그래서 **32px 이하에서는
노드 둘과 이음선 하나로 단순화**하고, 노드를 세로로 세워 이음선과 붙어 막대처럼 보이지 않게 했습니다.

### 다시 만들기

이미지 편집기 없이 코드로 그립니다.

```bash
swiftc -o /tmp/make-icon Mermark/Theme.swift Mermark/AppIcon.swift scripts/make-icon/main.swift
/tmp/make-icon /tmp/Mermark.iconset mint
iconutil -c icns /tmp/Mermark.iconset -o Mermark/Resources/Mermark.icns
```

그리는 코드는 앱과 공유합니다(`Mermark/AppIcon.swift`). 폴더 이름은 `iconutil` 요구대로
`.iconset`으로 끝나야 합니다.

`CFBundleIconFile`은 Xcode의 Info.plist 자동 생성이 지원하지 않는 키라
[`Config/Info.plist`](../Config/Info.plist)에 직접 적고, 나머지 키는 자동 생성분과 병합됩니다.

## 문서용 이미지

이 문서의 팔레트 이미지도 코드로 만듭니다. 색을 바꾸면 원본 HTML을 고치고 다시 렌더하세요.

```bash
swift scripts/render-html.swift docs/design/palette.html docs/palette.png 900 2
```

앱의 Mermaid 내보내기와 같은 방식(오프스크린 WKWebView + `takeSnapshot`)을 씁니다.
